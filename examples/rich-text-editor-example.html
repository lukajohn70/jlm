💻 Code Examples

Here are the JavaScript code examples for each editor implementation:

Basic Editor

const basicEditor = new RichTextEditor('basic-editor', { height: 300, placeholder: 'Start writing your content here...' });

Custom Editor

const customEditor = new RichTextEditor('custom-editor', { height: 400, placeholder: 'Write your amazing content with full formatting...', toolbar: [ 'bold', 'italic', 'underline', 'strikethrough', 'separator', 'alignLeft', 'alignCenter', 'alignRight', 'separator', 'bulletList', 'numberedList', 'separator', 'fontFamily', 'fontSize', 'textColor', 'backgroundColor', 'separator', 'link', 'image', 'separator', 'undo', 'redo', 'separator', 'clearFormat' ], onContentChange: (content) => { console.log('Content changed:', content); } });

Minimal Editor

const minimalEditor = new RichTextEditor('minimal-editor', { height: 200, placeholder: 'Write your comment...', toolbar: ['bold', 'italic', 'link'], onContentChange: (content) => { // Enable/disable submit button based on content const submitBtn = document.getElementById('submit-btn'); if (submitBtn) { submitBtn.disabled = !content.trim(); } } });
