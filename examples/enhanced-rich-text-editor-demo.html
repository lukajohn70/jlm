🎯 Key Features Explained

📹 Multimedia Support

Images, Videos, Audio - Insert any type of media with full formatting control:

  • Resizing: Click and drag to resize, or use the quick size buttons (25%, 50%, 75%, 100%)
  • Alignment: Left, center, or right align your media
  • Text Wrap: Wrap text around media elements for professional layouts
  • Double-click: Open the formatting modal for precise control

🎨 Typography

35+ Fonts & 20+ Sizes - Professional typography options:

  • Serif Fonts: Times New Roman, Georgia, Garamond, Baskerville
  • Sans-serif Fonts: Arial, Helvetica, Tahoma, Verdana
  • Decorative Fonts: Impact, Comic Sans MS, Brush Script MT
  • Monospace Fonts: Courier New, Consolas, Monaco
  • Font Sizes: From 8px to 64px, plus relative sizes

📝 Content Blocks

Quotes, Code, Sections - Structure your content professionally:

  • Quotes: Styled blockquotes with left border and background
  • Code Blocks: Syntax-highlighted code with monospace font
  • Section Breaks: Horizontal rules to separate content sections

🎯 Advanced Formatting

Full Justification & More - Professional text formatting:

  • Full Justification: Text aligned to both left and right margins
  • Text Colors: Custom color picker for text
  • Background Colors: Highlight text with background colors
  • Strikethrough: Cross out text for corrections or emphasis
